# skrishnan83.github.io

Personal portfolio website of Smita Krishnan: M.S. Computer Science (Concordia University Chicago), PhD in Applied Science, AWS Certified.

Live site: https://skrishnan83.github.io

## Contents
- `index.html` – the whole site (HTML and CSS in one file, no build step)
- `images/` – project posters (FISCAL, AURA)

## Updating
Edit `index.html` on GitHub (pencil icon) or locally, commit, and the site updates within a minute or two.
