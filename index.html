SECURITY · DATA STRUCTURES

VAULT – Verified Access and User Login Tracker

A secure mini password management and authentication system in C++

  • Registration, login, user search and account deletion, with deletion allowed only after authentication.
  • Passwords are hashed with SHA-256 before storage, so plain-text passwords are never kept.
  • An abstract hash table with two implementations, linear probing with tombstone deletion and separate chaining, switchable at runtime.
  • A built-in performance analysis reports capacity, load factor and collisions and compares the two strategies.
  • C++
  • SHA-256
  • Hash tables
  • UML
  • Ubuntu Linux
  • draw.io

OOP · CHEMISTRY

REACT – Relational and Educational Application for Chemistry Training

A C++ chemistry lab application built on object-oriented design

  • Models elements, compounds and reactions through an abstract Substance base class, with Element and Compound as derived classes.
  • Uses inheritance, polymorphism, encapsulation, copy constructors and smart pointers for safe memory management.
  • Menu-driven tool to add, list and search substances, define reactions and calculate properties such as density.
  • Brings my chemistry and chemical engineering background into software.
  • C++
  • OOP
  • Smart pointers
  • UML
  • Ubuntu Linux
  • draw.io

DATABASE DESIGN

AURA – Advanced Unified Repository for Atmospheric Data Management

A relational climate database in Oracle

  • 15-table relational model with a central location table linking sensors, temperature, humidity, rainfall, CO₂, air quality, emissions, deforestation, population, disasters, policies and forecasts.
  • DDL scripts with primary keys, unique and NOT NULL constraints, and cascade drops; ER schema drawn in draw.io.
  • Builds on my climate-science consulting work in Africa.
  • Oracle SQL
  • Relational design
  • ER modeling
